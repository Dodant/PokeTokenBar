# PokeTokenBar landing direction

## THESIS

Make the product and the installation path understandable before asking a visitor to read its game mechanics. A Mac developer should recognize a useful usage tracker and a companion they might enjoy.

## OWN-WORLD

The existing black app icon and red identity anchor a neutral, nearly white canvas. Rounded Bricolage Grotesque display letters bring a little playfulness; system body type supports the existing Korean and Japanese audiences. Product illustrations carry the Pokémon personality. No ornamental font costumes, gradients, glow, fake OS chrome, or testimonials.

## STORY

Product and example screen → installation steps and direct ZIP alternative → usage details → companion lifecycle and desktop demo → visible numerical field guide → all 14 supported tools with linked icons and names → practical questions → source and fan attribution. Existing #top, #features, #companion, #guide and #install anchors stay available. Detailed features use native disclosure controls. The growth guide is always expanded; its topic tabs remain. All provider links are visible without a disclosure.

## FIRST VIEWPORT

Left-aligned title, short product explanation, installation anchor, free/macOS compatibility line. The opposite column holds the existing example popover at a readable scale. On phones the same decision and installation link precede the illustration. The Home caption identifies a native production UI render with sample data in English. Other captions distinguish localized native samples from the retained English illustrations.

## FORM

Code-led, single static route; no approved generated comp. Existing screenshots were inspected as product evidence, not invented in the redesign. Seed 0ee2960c assigned candidate 3. Candidate vocabulary explored: Mac utility storefront; a trainer's field guide; a quiet desktop companion showcase (selected); a usage notebook; a software quick-start leaflet; a collectible species index; a coding-session diary. These span interface, documentation and collecting contexts.

The generated catalog's ornament plate book, Metro panorama, transforming cape, ikebana display, particle detector and hand-drawn zine were not adopted as visual costumes. Their structural lessons were considered: consistent units, clear live controls, reversible state, deliberate empty space, inspectable data and sequential explanation. The existing Mac product and its installation task remain the authority. No user preference is inferred from the seed and no permanent build-path preference was recorded.

## Verification scope

English, Korean and Japanese; light and dark themes; 320, 375, 414, 768, 1024, 1440 and 1920px. Clipboard success/rejection/unavailable, keyboard menu/tabs, anchor offsets, no JavaScript, blocked storage, missing hero image and reduced-motion behavior. Screenshot provenance is in PRODUCT.md. Actual app behavior is not retested by a landing-page browser suite.
